# アプリ開発プロンプト(Claude Code用)

## これは何のアプリか
- タイプ: モバイルアプリ(iOS / Xcodeプロジェクト)
- 一言で言うと: 写真を送るとその中に写っている食べ物や料理、飲み物の大まかなカロリーが計算され、一日の摂取カロリーを把握できる機能と万歩計、その日の運動内容を計算して消費カロリーを計算できるアプリ
- 想定ユーザー: 身近な人・チーム向け — 僕と僕の彼女

## 解決したい課題
僕の体重維持と彼女のダイエットに対応してほしい

## 必須機能(MVP)
- 写真から摂取カロリー、栄養素(主にたんぱく質と脂質)を推定
- 万歩計と運動内容を記録して消費カロリーを計算
- 目標を達成するために必要な食事メニュー「飲食店も可」を提案
- 目標を達成するために必要な運動(ジムメニューも可)を提案
- 任意で体重を記録(毎朝)
- BMIを計算
- ダイエットプランの提示(4か月で-5キロをするには一日のカロリーはどうすればいいのか)など
- 機能カスタマイズ→欲しい機能の要望をかなえる
- widgetとして待ち受け画面に表示できる機能
